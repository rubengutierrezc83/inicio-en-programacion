### Clase 1: GIT

Que es git, es un lenguaje de versionamiento de codigo.

comandos:
```
git status
git add *
git checkout -b "new_branch"
git checkout "branch"
git commit -m "message_commit"
git push
git pull
```
| command  |                      Description                      |
|----------|:-----------------------------------------------------:|
| git status |            ver el estatus del repositorio.            |
| git add * | Agregar archivos, eliminados, agregados o modificados |
| git checkout -b "new_branch"|    crear una rama nueva y posicionarse en esa rama    |
| git checkout "branch"|                  moverse entre ramas                  |
| git commit -m "message_commit"|   Poner un mensaje al cambio que se esta realizando   |
| git push|             Empujar los cambios a la nube             |
| git pull|        Traer los cambios realizados a la rama.        |
